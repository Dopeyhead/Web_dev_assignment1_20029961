# So You Want to Learn Japanese

## Project Purpose
This is my first attempt at writing a html website. The topic I choose is an introduction to learning the Japanese language, created
as a project for Web Development module in the Computer Science Certificate (2026/2027).

There are three main learning topic:
1. The Alphabet: Covering the three main Japanese Scripts. It shows all kana which is the first step for most learning the language.
2. Grammar: Covering a simplified description of sentence structure and the particles which mark different parts of the sentence (e.g. subject, object, time, etc.)
3. Vocab: Giving the basic greetings and questions that are often taught in rundimentary classes, as well as some more intermediate topics such as food. Before touching on some of the most common words in Japanese.

## Website

The website is made with HTML and CSS and can be viewed locally in a web browser. The browsers Floorp and Google Chrome were used for testing. 
It has been uploaded to github so that other users can have a look and posibly make changes. The pages were written in *HTML5* and *CSS3* was used for styling. 


## Webpages

* **Homepage:** Named index.html, this is the main landing page for the website. All the other pages (with the except of the hidden sutra page) can be accessed from here
* **Three main 'Learning' Pages:** Which are already described above in project purpose
    * *Alphabet*
   * *Grammar*
   * *Vocabulary* 
* **FAQ:** Answers common questions about learning Japanese and the language itself.
* **Resources:** Recommends some extra content as well as gives the sources used for the information on the website and the images directly to the user.
* **Heart Sutra:** This page is a purely visual page to show Kanji calligraphy for the buddist heart sutra in Japanese. It is not on the nav menu and can be accessed through the alphabet page.
