Extra Learning Resources

Learning Japanese is a long journey and this website only covers a very small taste of what you can learn and the ways to do it. See other resources below if you are interested in learning more.

Websites

  • Tofugu A website offering Japanese learning guides, explanations and advice for beginners. It also regularly has updates, with new learning resources and articles added to it.
  • Renshuu This is a learning resource similar to duolingo, that provides a structured program to progress through. Starting with the scripts you will need to know, then on to basic stuff like talking about your age, before progressing onto more complex topics like hobbies. It is similar to how a class or textbook would teach the language but is in a free and ad-free interactive format. Renshuu also has an mobile app that you can download on iOS or Andriod.

Mobile Apps

  • Anki A flashcard programme that helps you memorise vocabulary, kanji and other information through spaced repetition. You need to find flashcards decks that were created by other users or create your own if you wish. The computer version is free, but it is worth paying the small fee to get the mobile app and learn on the go.

Videos and YouTube Channels

  • Game Gengo Japan has a very large videogames industry and if you are interested in Japanese video games it can be rewarding to play them in their original language. The Game Gengo is a youtuber who creates many grammar and vocabulary videos covering different games. Even if you are not that interested in videogames, it can be worthwhile checking his vidoes out. His lessons on grammar are well done and he uses many examples.
